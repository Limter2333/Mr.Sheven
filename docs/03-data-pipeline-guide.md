# 数据端探针实验实施指南

> 原则：能手动就不自动。不做爬虫、不建正式库，火力集中在验证抽取质量上限。

## 第 0 步：准备物料（半天）

- 选 2 个博主 × 每人 3 期视频；优先"一期评多款酒"的横评类（对抽取能力压力最大）
- 记下 BV 号（注意：标准 BV 号为 12 位，即 BV + 10 个字符）
- 工具：`uv tool install yt-dlp`（全局 CLI）；ASR 走云端则 `uv add dashscope`

## 第 1 步：获取视频文本

**通道 A（优先）：CC / B 站 AI 字幕**
- `yt-dlp --list-subs` 查看；AI 字幕（ai-zh）藏在登录墙后，需 cookies.txt（见 05 文档）
- 优点：文本干净、免费、自带逐句时间戳

**通道 B（兜底）：ASR 转写**
- `yt-dlp -f bestaudio` 下载音频（m4a，无需 ffmpeg）
- 云端：qwen3-asr-flash-filetrans（异步、时间戳固定开启）；本地：faster-whisper
- 专有名词纠偏：云端用 `context` 参数 / 本地用 `initial_prompt`，塞入品类品牌词表
- 词表来源：博主历史视频标题；词表同时是别名表的种子数据

**两条铁律**：
1. 必须保留时间戳（产品要"跳转到博主说这句话的 12:34"；人工核对也靠它）
2. 产出统一归一为 `transcript.json`（带时间戳的文本），下游不感知来源通道

## 第 2 步：抽取目标 Schema

LLM 输出数组，每个元素 = 一款酒的评测记录：

| 字段 | 说明 |
|---|---|
| `product_name_raw` | 博主口中原话叫法（保留原始形态，归一化是下一层的事） |
| `brand` / `category` | 能推断则填，否则 null |
| `score_raw` + `score_type` | 原始评分及制式（百分制/十分制/无评分） |
| `verdict` | 推荐 / 中性 / 避雷 三档 |
| `quote` | 逐字摘录关键评价 1~3 句 |
| `timestamp_start` / `timestamp_end` | 该段评价在视频中的起止时间 |
| `confidence` | 模型自评置信度 |

**三条防幻觉纪律（写进提示词）**：
1. 只抽实际品尝/评测的酒，顺嘴提到的不算
2. 任何字段拿不准填 null，禁止编造
3. quote 必须逐字来自转写文本，不许改写（人工核对的锚点：quote 对不上原文 = 整条不可信）

## 第 3 步：LLM 抽取

- 探针阶段不写调用代码：对话界面手动粘贴"转写文本 + 提示词"，存返回的 JSON
  （本项目由 Claude Code 直接完成此步）
- 提示词四块结构：
  1. 角色与任务（酒类评测数据标注员，抽取所有被评测酒款）
  2. 输出 Schema（字段定义 + 取值规则 = 给模型的接口契约）
  3. 纪律（上面三条）
  4. Few-shot 示例 1 个（须包含"推断不出填 null"的样例）
- 20~40 分钟视频转写约 8 千~1.5 万字，长上下文模型一次吃得下，探针阶段不分段
- 若长视频漏抽 → 引入两遍法：第一遍只切分（哪个时间段评哪款酒），第二遍逐段抽取

## 第 4 步：人工核对与量化（产出 Go/No-Go 结论）

核对表（Excel 即可），每条记录对着视频核四件事：

| 核对项 | 判定 |
|---|---|
| 召回：视频里实际评的酒都抽出来了吗 | 数漏抽 |
| 酒名：`product_name_raw` 与视频一致吗 | 对/错 |
| 评分与倾向：`score_raw`、`verdict` 对吗 | 对/错 |
| 摘录：`quote` 能在转写文本逐字找到吗 | 能/不能 |

三个指标：**召回率**（漏抽最致命）、**字段准确率**、**幻觉率**（quote 对不上原文的比例）。
9 个视频约产出 30~60 条记录，样本量足够下结论。

同时记录：博主们实际的评价方式（打分 vs 口头、有无固定档位）→ 决定归一化规则设计。

## 第 5 步：结论分支

- 指标可接受 → 工程化：视频列表自动发现、批量转写、API 化抽取、审核队列、SQLAlchemy + Alembic 建库
- 指标不行 → 定位坏在哪一环，各有便宜修法，修完只重跑第 4 步：
  - ASR 酒名错太多 → 加词表 / 换云 ASR
  - 漏抽 → 两遍法
  - 幻觉 → 收紧提示词 / 换模型

## 工程约定

- 探针物料全部放 `probe/` 目录（转写文本、提示词版本、抽取结果、核对表），纳入 git
- 离线批处理与在线服务分开（≈ Maven 多模块里 batch job 与 web app 分模块）
- 凭证类文件（cookies.txt、API Key .env）一律放仓库外，见 05 文档安全纪律
